# AUGUSTEGO

Artist website: independent rap from Saint Petersburg.

Live preview: https://reborn22.github.io/augustego-website/

Static HTML, CSS and JavaScript. The deployable website lives in `dist/`.
GitHub Actions publishes it to GitHub Pages on every push to `main`.

For local preview, run `node preview.mjs` and open http://127.0.0.1:4173/.

The site presents the artist, the debut single «Сила», the visual archive and social links.
The release cover is square; the vertical clip opens in a dialog.
The masthead is deliberately minimal at the artist's request.

Artwork sources and generation prompts are in `artwork/`.
Font licenses are included in `dist/assets/`.
Music and artist materials belong to their respective rights holders.
